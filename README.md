# 크리스마스 밤바다 모닥불

달밤 바닷가 모닥불에 모여 앉는 three.js 가상 공간입니다.
링크를 연 사람들이 같은 바닷가에서 서로 만납니다(공개 MQTT 중계).
캐릭터는 Kenney Mini Characters, 소품 일부는 Kenney Nature Kit(둘 다 CC0)입니다.
눈 내리는 성탄 밤입니다. 바다에서 헤엄칠 수 있고, 「사진」 버튼이나 P키로 지금 장면을 저장합니다.

바닷가에 나무 부두가 있습니다. 끝까지 걸어가 점프하면 다이빙하고, 옆 낚시 판자의 의자에 앉으면(E) R 키로 낚싯대를 던질 수 있습니다. 바다는 에메랄드빛으로 맑아 얕은 곳 바닥이 비치고, 헤엄치다 C 키를 꾹 누르면(모바일은 「잠수」 버튼) 물속으로 잠수합니다.

## 인면 거미 보스

「보스 생성」 버튼(오른쪽 아래)을 누르면 인면 거미가 올라옵니다. 화면 위 체력 바가 0이 되면 쓰러지고, 「보스 삭제」로 언제든 지울 수 있습니다. 내려찍기(좌클릭·F)로 때립니다.
패턴 넷 — 앞다리 휘두르기(근접) · 독침 3발(맞으면 잠깐 느려짐) · 거미줄 장판(밟으면 이동이 느려짐) · 새끼 거미 소환(플레이어를 쫓아와 뭅니다). 체력이 35% 아래면 분노해 더 빠르고 자주 공격합니다.
접속자끼리 같은 보스를 봅니다: 보스를 만든 사람 화면이 AI 를 돌리고 `brx-bonfire-v1/nd/boss` 로 초당 8번 상태를 보내며(소유자가 나가면 가장 작은 id 가 이어받음), 내가 맞았는지는 내 화면에서 판정합니다.
모델(`bf/spider.glb`, 새끼 `bf/spider_mini.glb`)은 Blender 파이썬 스크립트로 만듭니다: `blender -b --factory-startup --python tools/spider/build_spider.py -- both --out bf [--preview <폴더>]`. 로직 검사는 `node tools/spider.test.mjs`.
