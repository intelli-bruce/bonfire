# 크리스마스 밤바다 모닥불

달밤 바닷가 모닥불에 모여 앉는 three.js 가상 공간입니다.
링크를 연 사람들이 같은 바닷가에서 서로 만납니다(공개 MQTT 중계).
캐릭터는 Kenney Mini Characters, 소품 일부는 Kenney Nature Kit(둘 다 CC0)입니다.
눈 내리는 성탄 밤입니다. 바다에서 헤엄칠 수 있고, 「사진」 버튼이나 P키로 지금 장면을 저장합니다.

바닷가에 나무 부두가 있습니다. 끝까지 걸어가 점프하면 다이빙하고, 옆 낚시 판자의 의자에 앉으면(E) R 키로 낚싯대를 던질 수 있습니다. 바다는 에메랄드빛으로 맑아 얕은 곳 바닥이 비치고, 헤엄치다 C 키를 꾹 누르면(모바일은 「잠수」 버튼) 물속으로 잠수합니다.

## 인면 거미 보스

「보스 생성」 버튼(오른쪽 아래)을 누르면 인면 거미가 올라옵니다. 크고 동그란 눈에 볼터치, 웃는 입과 작은 송곳니를 가진 귀여운 거미이고, 키는 머리 꼭대기가 약 13 m(캐릭터의 8~9배), 다리를 펴면 폭 약 45 m 입니다. 가까이 가면 화면이 자동으로 멀어져 전신이 보입니다. 화면 위 체력 바가 0이 되면 쓰러지고, 「보스 삭제」로 언제든 지울 수 있습니다. 때리는 곳은 다리 아랫부분이며(내려찍기: 좌클릭·F), 배 밑을 걸어 지나갈 수 있습니다.
패턴 넷 — 앞다리 휘두르기(근접, 앞쪽 부채꼴) · 독침 3발(입에서 내 쪽으로 내리꽂힘, 맞으면 잠깐 느려짐) · 거미줄 장판(밟으면 이동이 느려짐) · 새끼 거미 소환(플레이어를 쫓아와 뭅니다). 체력이 35% 아래면 분노해 더 빠르고 자주 공격합니다. 잔털은 몸통·다리에 듬성듬성만 있습니다.
접속자끼리 같은 보스를 봅니다: 보스를 만든 사람 화면이 AI 를 돌리고 `brx-bonfire-v1/nd/boss` 로 초당 8번 상태를 보내며(소유자가 나가면 가장 작은 id 가 이어받음), 내가 맞았는지는 내 화면에서 판정합니다.
모델(`bf/spider.glb`, 새끼 `bf/spider_mini.glb`)은 Blender 파이썬 스크립트로 만듭니다: `blender -b --factory-startup --python tools/spider/build_spider.py -- both --out bf [--preview <폴더>]`. 로직 검사는 `node tools/spider.test.mjs`.

## 무기 (숫자 1~4 · 마우스 휠)

보스·새끼 거미를 잡는 무기 넷을 숫자키로 바꿔 씁니다. 화면 왼쪽에 슬롯 목록이 있고(현재 무기 강조), 마우스 휠로도 바뀝니다(카메라 확대는 Shift+휠). 모바일은 오른쪽 「무기」 버튼으로 순환하고 「사격/베기」 버튼(총은 꾹 누르면 연사), 총을 들면 「장전」 버튼이 생깁니다.

| 키 | 무기 | 공격 |
|---|---|---|
| 1 | 맨손 | 내려찍기(기존) |
| 2 | 검 | 3연 베기 + 휘두를 때마다 날아가는 초승달 검기(원거리 약 30 m). 3타는 크고 센 검기 |
| 3 | M4A1 | 연사(초당 약 10발), 탄창 30발 · 예비탄 90발, 빈 탄창은 자동 장전, R 장전 |
| 4 | 산탄총 | 산탄 7발, 탄창 6발 · 예비탄 24발, R 로 한 발씩 장전(장전 중에도 쏘면 멈춤) |

- 총은 화면 가운데 조준점으로 쏩니다(보스·새끼에 겹치면 붉게). 몸은 카메라 방향을 보고, 시점이 오른쪽 어깨 위로 비껴 총구·탄 궤적이 가려지지 않습니다. 총구 섬광·탄 궤적·탄피·반동, HUD 탄창/예비탄과 장전 진행 막대가 있습니다.
- 탄창을 다 쓰면 총이 쏜 뒤 자동으로 장전합니다(소총: 탄창 빼기 → 새 탄창 끼우기 → 빈 탄창이면 장전 손잡이 당기기). 예비탄까지 다 쓰면 8초 뒤 한 탄창분이 보급됩니다. 앉아 있을 때 R 은 낚싯대입니다(총을 들고 있어도).
- 기존 1·2·3 감정 표현은 **7 춤 · 8 환호 · 9 끄덕**으로 옮겼습니다(오른쪽 「춤」 버튼은 그대로).
- 피해는 보스·새끼 거미에만 들어갑니다. 소유자 방식은 그대로: 맞힌 사람 화면이 판정해 `wpn` 주제(`brx-bonfire-v1/nd/wpn`)로 사격·휘두름·장전·피해 보고를 보내고, 보스를 돌리는 소유자가 **무기별 피해 표**(`bf/weapons-core.js`)로 HP 를 깎습니다(보낸 사람이 말한 값은 쓰지 않음, 거리·간격 검사). HP 는 보스 스냅샷으로 모두에게 갑니다. 남의 총구 섬광·탄 궤적·검기·장전도 보입니다. 접속자의 무기는 현재 위치 정보의 `wp` 필드로 손에 들려 보입니다.
- 모델(`bf/sword.glb`, `bf/m4a1.glb`, `bf/shotgun.glb`)은 Blender 파이썬 스크립트로 만듭니다: `blender -b --factory-startup --python tools/weapons/build_weapons.py -- all --out bf [--preview <폴더>]` (렌더: `tools/weapons/preview/`). M4A1 은 상·하부 리시버, 윗면 피카티니 레일, RIS 4면 레일 핸드가드, A2 소염기, 접이식 가늠자, 6단 신축 개머리판, STANAG 30발 탄창(탄창·장전 손잡이·노리쇠는 따로 움직입니다).
- 로직 검사는 `node tools/weapons.test.mjs`(탄약·장전·콤보·피해 표·광선 수학·메시지 검증·보스 `hitRay`). 로컬(127.0.0.1)에서 `?room=이름` 을 붙이면 테스트용 비공개 주제를 써서 공개 모닥불에 보이지 않습니다.
